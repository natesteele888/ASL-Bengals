ASL Bengals — 11U

One team, a family of small apps instead of one big one.

Every piece here reads and writes the same live team data — there's no single "master" app, just several purpose-built tools that all trust the same source of truth.

How the pieces connect

The gold node is the shared backend. Everything below it is a separate tool that reads from and writes to it directly — none of them talk to each other except through that shared data.
Shared Backend

Firebase Realtime Database

One live database behind everything. A play logged on the sideline, a roster change, a new standings paste — it's visible everywhere else within a page reload.

Main App

Live · daily use
Players, coaches, parents

The hub everyone actually lives in: Study Guide, Signal & Play Calls, Schedule, Roster, 2-Minute Drill, leaderboard, and Coach Tools (stats, depth chart, dashboard). Most of a season happens here.

Reads & writes almost everything in the shared backend

Game Wizard

New · Phase 1 done
Coach Nate only, for now

Guided, step-by-step live game setup — GameChanger-style. Confirm starters from the depth chart, run the coin toss, log the opening kickoff. Hands off into Stat Keeper for the rest of the game while the full snap-by-snap wizard gets built out.

Writes the opening kickoff into statKeeperLogs

Stat Keeper

Live · becoming the "fix-it" tool
Coaches

Play-by-play entry with a field position and down & distance tracker for every play type. Today it's the main way a game gets logged; once the Wizard's full play-calling flow exists, this becomes the tool for correcting anything the Wizard got wrong.

Reads & writes statKeeperLogs, reads schedule/teamRoster

Game Playback

New
Coaches (kids next)

Takes a game someone already logged and replays it — a moving ball, drive-by-drive field position, down & distance, box score. Built directly on top of whatever Stat Keeper or the Wizard already recorded; nothing new to log.

Reads statKeeperLogs, schedule, opponentLogos
